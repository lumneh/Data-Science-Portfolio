# Data-Science-Portfolio

Welcome to my Data Science portfolio — a collection of real-world projects using data, machine learning, and AI to solve business problems. It showcases end-to-end workflows including data cleaning, analysis, feature engineering, modelling, evaluation, and deployment-ready solutions that transform data into actionable business insights.

## Featured Project

### Credit Score Classification & Monitoring System

An end-to-end machine learning system for classifying customer credit scores into **Good, Standard, and Poor** categories using XGBoost.

The project demonstrates the complete machine learning lifecycle, from data validation and feature engineering to model development, explainability, deployment, and production-style monitoring.

**Key components:**

- Data cleaning, validation, and feature engineering
- Customer-level train/validation/test splitting
- XGBoost model development and hyperparameter tuning
- Model evaluation using accuracy and macro-averaged metrics
- SHAP-based model explainability
- FastAPI REST API for model serving
- Interactive Streamlit application
- Model and data drift monitoring
- Reproducible notebooks and deployment artifacts

**Technologies:** Python · Pandas · NumPy · Scikit-learn · XGBoost · SHAP · FastAPI · Streamlit 

**Model Performance:** 70.79% Accuracy · 68.58% Macro F1
